# ShouxingCare User Manual

User manual for **ShouxingCare**, a voice-first AI companion device, powered by [Transtak Pte Ltd](https://www.transtak.com.sg).

> **Trial version.** ShouxingCare is in its trial period. Features, performance and appearance may change without notice, the emergency feature may not be 100% reliable (always use your local emergency services as well), and no warranty applies. See the Important Notice in the manual.

## What's inside

| # | Section | Summary |
|---|---------|---------|
| 01 | Setting up the device | Create a family account with an email and password |
| 02 | Binding the device | Use **Bind a Device** with the device's MAC address and claim code |
| 03 | Device connected | Open the device card to see its customisation options |
| 04 | Let's customize | Voice (10 types), user precondition prompt, alert rules, and speech sensitivity (speech threshold, silence hangover, reply loudness floor) |
| 05 | Who will receive the alerts? | Per-recipient toggles for reminders and emergency alerts |
| 06 | Let's create the bot | Create a Telegram bot with BotFather and get your Chat ID from `@userinfobot` |
| 07 | Family photos | Up to 6 photos shown as a slideshow when the device is idle (a clock is shown without photos) |
| 08 | Tell the AI about your habits | Knowledge Base entries for medication schedules, routines, contacts and household rules |

## Quick start

1. Create a family account.
2. Bind your device with its MAC address and claim code (request these from Transtak).
3. Customise the voice, alert rules and sensitivity.
4. Set up alert recipients and connect Telegram (bot token and Chat ID).
5. Add family photos and Knowledge Base entries.
